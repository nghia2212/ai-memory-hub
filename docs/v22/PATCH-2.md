# V2.2.2 long prompt editor

Plan, task and brain objectives accept up to 32,000 characters. Dashboard preserves original objective and only appends bounded references. Drafts are scoped to project/worktree in browser sessionStorage (not encrypted; do not enter secrets). TXT/MD import appends UTF-8 text locally, not separate persisted attachments. Expanded editor is viewport-height, not fullscreen. Windows CLI launch limits may be lower than storage limit; unsupported oversized arguments fail explicitly rather than truncate. No automatic splitting or selective semantic context optimization in this patch. No database migration. Update host runner source and restart existing host runner as appropriate, rebuild memory-bridge/dashboard, run health and regression tests. Tests added, runtime verification pending.
