Validate tool arguments, bound response size, HTTP timeouts, concurrency, TLS and approved endpoints; no arbitrary URL forwarding/SSRF, no automatic paid fallback.
- Deterministic mock adapter and replay synthetic fixtures; no network on startup, indexing, search or unit tests. Connection test defaults to no paid request; an explicit separately approved real minimal call may verify capability and usage.

## P16 — Hub-managed Agent Execution Engine (Lead + Agent C)
- Integrate with existing Plan/Task/Attempt/runner contracts; no second scheduler. MVP: user submits scoped task, approved plan/model/budget, bounded execution loop: resolve context -> provider call -> validate tool call -> policy gate -> execute -> return bounded result -> final response -> QA -> handoff. Multi-step tool calls, cancellation, timeouts, maximum rounds/calls/runtime/output and retry ceilings. State persists durably; crash recovery/reconciliation, idempotency for tool operations; never blindly repeat a write or a request with uncertain billing. Record real attempt/request/tool IDs. Stop with explicit reason for unsupported tools, unavailable runtime or budget.
- Start with read-only codebase inspection; enable code edits only via existing verified write-capable runner and explicitly approved scoped disposable worktree. Implement safe diff/patch, path canonicalization and symlink/junction checks, isolated test commands via allowlist, bounded stdout/stderr; no arbitrary shell execution or Docker socket. Keep indexer read-only. No destructive commands, secret access, network exfiltration, git push/merge/deploy without separate permission; user approves diff/commit as configured, and production/main actions separately. If no safe write runner exists, report blocked and deliver patch for review, never bypass.
- Tool output and retrieved content untrusted; not authority to broaden scope or budgets. Human approval tied to exact action/arguments/worktree/revision, expiring and auditable. Tests for injection, cross-project traversal, cancellation, restart and ambiguous side effects.

## P18 — Token / Thinking / Budget Controller (Agent A + Lead)
- Reuse P11 normalized usage ledger and P12 dashboard. - Budget limits at task/plan/project/profile, explicit paid opt-in, default external paid calls disabled until user configures positive finite budget.
