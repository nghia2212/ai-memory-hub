# Proposed V3 API / contract
Lead freezes after V2 integration; no implementation yet. REST /v3 on Bridge sole writer, typed strict JSON, UUID scope, UTC timestamps, revision CAS (If-Match or expected_revision), idempotency key on mutations, cursor pagination max 100, bounded result sizes. 401/403/404/409/422/429/503 typed errors; no secret or full host path in errors. Reuse V2 actor and project/worktree roles; new explicit mcp_admin, mcp_runtime, mcp_invoke privileges mapped by server, not client assertions.
## Endpoints
GET /v3/plugins (read scoped view); POST /v3/plugins/import (admin; parse only, no execution); GET /v3/plugins/{id}; PUT /v3/plugins/{id}/revisions (admin creates quarantined immutable revision); POST /v3/plugins/{id}/verify (admin records provenance, reviewed permissions); POST /v3/plugins/{id}/install|update|rollback|uninstall (admin approves exact manifest hash; async job record); GET /v3/operations/{id}.
PUT /v3/plugins/{id}/enabled (admin desired state, disable revokes new leases); POST /v3/plugins/{id}/probe (admin, no implicit install); GET /v3/plugins/{id}/tools (scoped verified schemas); GET /v3/catalog and POST /v3/catalog/refresh (read/admin; candidate only).
GET/POST /v3/profiles; PUT/DELETE /v3/profiles/{id} (admin CAS); POST /v3/profiles/{id}/activate (admin, validated resource plan, no implicit grant); GET/PUT /v3/grants (admin; project/worktree/agent/role, plugin revision/tool, path/network scope, expiry, action class, approval reference). 
POST /v3/leases/acquire|heartbeat|release (runtime/invoke bound to approved plan/job/agent); GET /v3/instances (scoped); POST /v3/instances/{id}/drain (admin); POST /v3/kill-switch (admin; audit and revoke); GET /v3/resources (measured/estimated/unavailable per instance and host).
POST /v3/tools/search (scope, query, limit default 5 max 20, approved profile/plan); POST /v3/tools/schema (stable tool ID, expected schema hash); POST /v3/tools/invoke (bound lease, tool ID/hash, typed args, idempotency, approval, deadline, output budget). Gateway handles execution with short-lived scoped capability; Bridge records lifecycle only. Tool response result/structured content bounded, truncated flag, artifact refs local by default, call ID, elapsed_ms, typed error. No raw binary in logs.
POST /v3/code/execute (scoped approved workflow/script revision, explicit allowed tool IDs, max calls, deadline and output budget); GET /v3/executions/{id}; POST /v3/executions/{id}/cancel. Script never inherits admin.
GET/POST /v3/workflows; PUT /v3/workflows/{id}/revisions; POST /v3/workflows/{id}/approve|run|rollback; version/hash, schema pins, input/output schema, grant requirements, evidence and dry-run. New revision invalidates approval.
GET /v3/audit; GET /v3/usage; GET /v3/analytics (project scope, baseline vs gateway measured, V2 sessions links).
## Gateway protocol
MCP initialize, tools/list and tools/call per negotiated protocol. Stable facade tool names mcp_search, mcp_get_schema, mcp_invoke, mcp_execute (proposed custom names, not upstream APIs). Optional direct namespaced tool exposure only scoped approved profile. Tool list notification where supported. All four tools enforce same policy; hidden tool is not security control. No agent admin methods exposed. Server-side auth bound to registered session, never trust project_id alone. Legacy client reinitialize on tool change. 
## V2 integration
Plan revision includes requested profiles, exact plugin/tool/schema revisions, grant snapshot, installation prerequisite, resource estimate and expected calls, egress approval and budget. Planner cannot grant or install. Atomic approval binds manifest hashes and resource caps. Runner leases acquire only approved tasks; stale/revoked grant denies even active session. Telemetry joins V2 session_id/task_id/attempt_id/plan_revision_id; count only actual provider usage, not tool bytes converted to exact tokens. Keep V2 endpoint compatibility; add nullable extension fields or separate relation with migration.
