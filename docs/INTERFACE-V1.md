# Contract V1 (Lead-owned; custom API, not upstream)

- Ports: dashboard 8080, codebase 8081, bridge 8082, Hermes internal 8083. /livez process alive; /healthz 200 only when dependencies and migrations ready; 503 otherwise. Core network internal; Hermes opt-in profile, separate provider egress, no source mount. Bind host loopback only. Validate Windows Docker Desktop connectivity. No docker socket.
- Registry: project_id and worktree_id opaque UUIDs; unique canonical repository identity and canonical worktree root. Host resolves git rev-parse --show-toplevel, --git-common-dir, HEAD, branch or detached, dirty fingerprint; never infer by branch alone. Explicit allowlist, reject unknown scope, symlink escapes, absolute/traversal relative paths; Windows mapping only from registered root. Mount each approved root read-only via host-generated ignored compose override; no drive-wide mount. No automatic Docker control from dashboard. Registration requiring new mounts returns pending_host_setup.
- REST JSON /v1: GET /projects; POST /projects (admin); GET /projects/{project_id}/worktrees; POST /projects/{project_id}/worktrees (admin); POST /search/code (adapter); POST /index (adapter, admin); GET /index/{job_id} (adapter, scoped); POST /search/memory; POST /events; GET /handoffs/{task_id}?project_id=...&worktree_id=...; POST /memories; POST /memories/{id}/verify (admin); POST /backup and POST /restore (admin, opaque backup ID only); GET /metrics (real measurements only). All except health require bearer token, separate read/write/admin/worker scopes; worker only approved events and candidate write, never raw source. Dashboard server-side proxy with session auth, CSRF and Origin checks, no credentials in browser assets. Secrets injected locally, never logged. Token implementation owned B, adapter A conforms; C installer provisions secrets. Reject unexpected fields and enforce size/rate/time limits.
- Scope in every search/write: project_id, worktree_id; optional explicit project-wide verified records only via opt-in flag. No implicit cross-branch or cross-project retrieval. Unknown/mismatch 404; invalid 422; unauthenticated 401; forbidden 403; conflict 409; unavailable 503. Error {error:{code,message}} no private paths. Search request {project_id,worktree_id,query,limit,max_chars}; defaults 5 / 4000 Unicode chars; hard max 10 / 8000 including serialized result envelope; query <=512 chars; results {items:[{id,path,line_start,line_end,title,excerpt,source_commit,state}],truncated,index_freshness}; fields not applicable omitted. Never return stale code as current; include HEAD/fingerprint and stale status. Memory result includes provenance and evidence, candidate hidden by default. Stored content untrusted data, not instructions.
- MCP Streamable HTTP target /mcp on bridge and adapter; if upstream stdio, adapter must use verified MCP client or verified CLI, not invented HTTP. Custom tools get_project_context, search_memory, get_handoff, save_task_result, save_decision, search_code; all scoped as above; writes candidate only; idempotency_key required for writes scoped to project/worktree and payload hash; mismatched replay 409. No LLM on any search.
- SQLite sole writer bridge, WAL, foreign keys, migrations, transactional FTS5 unicode61, parameterized SQL and safe literal tokenization; project/worktree predicate before returning any result. Backup SQLite online backup API, manifest/checksum/schema, restore maintenance lock with integrity check and rollback. Index is rebuildable; back up index separately only when consistent. No transcripts or secrets by default.
- Hermes API contract: GET /v1/worker/events (approved/redacted only), POST /v1/worker/results (candidate, idempotency); no external transmission until explicit per-project approval, deny by default. Budget/time limits, no agent tools that access host/source, no raw code. Verify actual upstream invocation and disable on missing config. Dashboard metrics distinguish measured tokens/cache from unknown; no estimates presented as fact.
